# 人格定时/口令切换插件（MaiBot）

给麦麦加一层**临时人格**：到了设定时段，或指定的人发一句暗号，麦麦就会换一种说话方式；时间一到自然回到原人格。

**全程只改运行时提示词，不修改 `bot_config.toml` 里的任何人格设定**，卸载插件或关闭开关后立刻恢复原样。

---

## 功能亮点

| 能力 | 说明 |
|---|---|
| 定时人格 | 每天固定时段自动切换，支持跨天（如 `23:00–07:00`） |
| 口令人格 | 白名单 QQ 发暗号立即切换，持续 N 分钟后自动恢复 |
| 转场词 | 切换时自动发一条提示消息，文本可自定义、可关闭 |
| 优先级清晰 | 口令人格 > 定时人格 > 原人格 |
| 零侵入 | 不动任何配置文件，纯运行时覆盖 |
| 可视化配置 | 所有参数都在 WebUI 插件配置里，保存即热重载 |
| 无后台任务 | 不驻留协程，全部在 Hook 内即时判断，没有僵尸任务风险 |
| 抗版本差异 | 多种提示词替换策略 + 兜底写法，结构对不上时打 warning 而不是静默失败 |

---

## 工作原理

插件通过 4 个 Hook 介入，不改主程序的提示词构建逻辑：

| Hook | 作用 |
|---|---|
| `chat.receive.before_process` | 解析入站消息，判断白名单与暗号；定时时段的首条消息触发转场词 |
| `maisaka.planner.before_request` | 替换 planner 系统提示词里的「XX 的行为风格：…」段落 |
| `maisaka.replyer.before_request` | 给本次回复追加一条「临时人格优先」的要求（兜底） |
| `maisaka.replyer.before_model_request` | 替换 replyer 系统提示词里的身份段 |

两个关键设计：

1. **只替换人格相关段落，保留其余约束**
   - replyer：只替换开头到「现在请你读读之前的聊天记录」之前的身份段，后面的说话格式要求、输出限制全部保留，避免换人格后输出格式崩坏。
   - planner：只替换行为风格段落，`Using your tools` 等工具说明保持不变，避免规划能力下降。
2. **多重兜底**
   - 如果找不到可替换的段落，会在系统提示词开头插入「【临时人格（优先级最高）】」。
   - replyer 还会额外追加一条人格要求，双保险。

## 安装

### 方式一：插件中心（收录后）

在麦麦 WebUI 的插件市场里搜索「人格切换」，直接安装。

### 方式二：手动安装

1. 下载本仓库，把整个文件夹放到麦麦的 `plugins/` 目录，例如：

   ```
   MaiBot/plugins/maibot-persona-switch/
     _manifest.json
     plugin.py
     config.toml
   ```

2. 等待插件文件监视器自动重载，或在 WebUI 里重载插件。
3. 打开 WebUI → 插件 → 「人格定时/口令切换」，确认配置项已出现。

## 配置说明

所有配置都在 WebUI 中可编辑，也可以直接改 `config.toml`（保存后热重载生效）。

### 插件

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 插件总开关 |

### 定时人格 `[schedule]`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `false` | 是否启用定时切换 |
| `start_time` | str | `"23:00"` | 开始时间，`HH:MM` |
| `end_time` | str | `"07:00"` | 结束时间，`HH:MM`；小于开始时间即视为跨天 |
| `persona` | str | 示例 | 时段内使用的临时人格文本 |

时间判断规则：包含开始时刻、不包含结束时刻。例如 `23:00–07:00` 表示 23:00 生效、07:00 整恢复。

### 口令人格 `[phrase]`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 是否启用口令切换 |
| `whitelist_qq` | list[str] | `[]` | 允许触发口令的 QQ 号 |
| `secret_phrase` | str | `"/变身"` | 暗号，消息中包含该文本即触发 |
| `duration_minutes` | int | `5` | 生效多少分钟后自动恢复 |
| `persona` | str | 示例 | 口令触发后使用的人格文本 |

### 转场词 `[transition]`

| 字段 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 切换时是否发一条提示消息 |
| `text` | str | `"【人格切换】换了个样子喵~"` | 提示文本，留空则不发送 |

转场词发送时机：

- 口令触发：在发暗号的那个会话里立刻发送。
- 定时触发：进入时段后的第一条消息，在该会话发送一次；离开时段后自动重置。

### 配置示例

```toml
[schedule]
enabled = true
start_time = "23:00"
end_time = "07:00"
persona = """你现在是「深夜电台主持人」：语速慢、句子短，用低沉温和的语气，喜欢用比喻，自称"我"，句尾不带"喵"。"""

[phrase]
enabled = true
whitelist_qq = ["123456789"]
secret_phrase = "/变身"
duration_minutes = 30
persona = """你现在切换成「傲娇侦探」：说话带点得意和怀疑，喜欢反问，自称"本侦探"，句子依然简短。"""

[transition]
enabled = true
text = "【人格切换】换了个样子喵~"
```

## 使用示例

**1. 深夜自动换人格**

```toml
[schedule]
enabled = true
start_time = "23:00"
end_time = "07:00"
```

23:00 之后的第一条消息会先收到转场词，随后麦麦按「深夜电台主持人」人格聊天；07:00 之后自动恢复原人格。

**2. 临时切换 30 分钟**

```toml
[phrase]
whitelist_qq = ["123456789"]
secret_phrase = "/变身"
duration_minutes = 30
```

`123456789` 在群里发 `/变身` → 立刻切换并回一条转场词 → 30 分钟后自动恢复。非白名单用户发同样内容不会有任何反应。

## 常见问题

**Q：改完配置要重启吗？**
不需要。保存 `config.toml` 或 WebUI 配置后会自动热重载，下一次请求即生效。

**Q：到点了为什么没看到变化？**
人格是在「下一次 LLM 请求」时替换的，所以需要有对话发生。定时转场词会在进入时段后的第一条消息时发送（时段开始前没有会话上下文，无法主动发消息）。

**Q：跨天时间段怎么写？**
`start_time = "23:00"`、`end_time = "07:00"` 即可，结束时间小于开始时间就按跨天处理。

**Q：会覆盖我的 `bot_config.toml` 吗？**
不会。插件只读取 Hook 传入的本次请求提示词并临时改写，不写回任何配置文件。卸载插件立即恢复原人格。

**Q：为什么不整体替换系统提示词？**
整体替换会丢掉输出格式约束和工具使用说明，容易导致回复格式崩坏或规划能力下降。插件只替换人格段落，保留其余部分。

**Q：需要什么权限？**
`gateway.route`（接收消息事件）、`send.text`（发送转场词）、`config.get`（读取配置）。

**Q：支持哪些版本？**
实测环境：MaiBot 1.3.9 + MaiBot Plugin SDK 2.14.0。
manifest 声明兼容范围：Host `1.0.0–1.9.99`，SDK `2.0.0–2.14.99`。
